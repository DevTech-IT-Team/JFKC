# Google Sheets integration for the JF Knowledge Centre contact form

This procedure connects the coded contact form in `src/pages/Contact.jsx`
directly to a Google Sheet through Google Apps Script. It does not use Google
Forms.

## Fields written to the Sheet

The website sends URL-encoded fields with these names. Keep the names in the
React form and Apps Script in sync.

| Sheet column | Contact form field | Request parameter | Required |
| --- | --- | --- | --- |
| Submitted At (date and time) | Generated by Apps Script when received | — | Yes |
| Name | Name | `name` | Yes |
| Phone | Phone | `phone` | Yes |
| Email | Email | `email` | Yes |
| Message | Enter Your Message | `message` | No |

The timestamp is intentionally not an editable contact-form field. Apps Script
adds it when the submission reaches the Sheet, so it reflects the server's
receipt time rather than a visitor-supplied value. The Contact form tells
visitors that this timestamp is recorded automatically.

## 1. Create the response spreadsheet

1. Create or open the Google Sheet where contact submissions should be stored.
2. From that spreadsheet, choose **Extensions → Apps Script**. This creates a
   script bound to the spreadsheet so the setup function can save its ID for the
   web app.
3. Replace the Apps Script editor contents with the full script below and save.
4. Select `setupContactSheet` in the function list and run it once. Approve
   spreadsheet permissions. It names the current tab **Contact submissions**,
   adds the recommended header row if the sheet is empty, validates existing
   headers without changing their order or existing data, and saves this
   spreadsheet's ID for the web app. It does not create another spreadsheet.
   It supports both `Submitted At, Name, Phone, Email, Message` and the earlier
   setup's `Name, Email, Phone, Message, Timestamp` order.
5. In Apps Script **Project Settings**, set the time zone you want recorded
   (for example, **(GMT+05:30) India Standard Time**). The timestamp is generated
   by Apps Script when a valid contact submission is received.

```javascript
const SHEET_TAB_NAME = 'Contact submissions';
const EXPECTED_HEADERS = [
  'Submitted At',
  'Name',
  'Phone',
  'Email',
  'Message'
];

function setupContactSheet() {
  const spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  if (!spreadsheet) {
    throw new Error(
      'Open Apps Script from the response spreadsheet and run setupContactSheet there.'
    );
  }

  const sheet = spreadsheet.getSheets()[0];
  if (!sheet) {
    throw new Error('The response spreadsheet does not contain a sheet tab.');
  }

  sheet.setName(SHEET_TAB_NAME);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(EXPECTED_HEADERS);
  }
  const headerMap = getHeaderMap_(sheet);
  sheet.getRange(1, headerMap.timestamp, sheet.getMaxRows(), 1)
    .setNumberFormat('yyyy-MM-dd HH:mm:ss');

  PropertiesService.getScriptProperties().setProperty(
    'CONTACT_SPREADSHEET_ID',
    spreadsheet.getId()
  );
  Logger.log('Contact sheet is ready: ' + spreadsheet.getUrl());
}

function doGet() {
  return jsonResponse_({
    ok: true,
    message: 'JF Knowledge Centre contact endpoint is active.'
  });
}

function doPost(e) {
  try {
    const spreadsheetId = PropertiesService.getScriptProperties()
      .getProperty('CONTACT_SPREADSHEET_ID');
    if (!spreadsheetId) {
      throw new Error('Run setupContactSheet from the response spreadsheet first.');
    }

    // The React contact form submits URLSearchParams, which Apps Script exposes
    // as e.parameter (not JSON in e.postData.contents).
    const fields = e && e.parameter ? e.parameter : {};
    const name = cleanField_(fields.name, 200);
    const phone = cleanField_(fields.phone, 50);
    const email = cleanField_(fields.email, 254);
    const message = cleanField_(fields.message, 5000);

    if (!name || !phone || !email) {
      return jsonResponse_({
        ok: false,
        error: 'Name, phone, and email are required.'
      });
    }
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      return jsonResponse_({ ok: false, error: 'Enter a valid email address.' });
    }

    const sheet = SpreadsheetApp.openById(spreadsheetId)
      .getSheetByName(SHEET_TAB_NAME);
    if (!sheet) {
      throw new Error('The "' + SHEET_TAB_NAME + '" sheet tab was not found.');
    }
    const headerMap = getHeaderMap_(sheet);

    const lock = LockService.getScriptLock();
    lock.waitLock(10000);
    try {
      const row = new Array(sheet.getLastColumn()).fill('');
      row[headerMap.timestamp - 1] = new Date();
      row[headerMap.name - 1] = safeCell_(name);
      row[headerMap.phone - 1] = safeCell_(phone);
      row[headerMap.email - 1] = safeCell_(email);
      row[headerMap.message - 1] = safeCell_(message);
      sheet.appendRow(row);
    } finally {
      lock.releaseLock();
    }

    return jsonResponse_({ ok: true });
  } catch (error) {
    console.error(error);
    return jsonResponse_({
      ok: false,
      error: 'The submission could not be saved. Check Apps Script executions.'
    });
  }
}

function getHeaderMap_(sheet) {
  const headers = sheet
    .getRange(1, 1, 1, sheet.getLastColumn())
    .getDisplayValues()[0]
    .map(function (header) {
      return String(header).trim().toLowerCase();
    });

  const aliases = {
    timestamp: ['submitted at', 'timestamp'],
    name: ['name'],
    phone: ['phone'],
    email: ['email'],
    message: ['message']
  };
  const headerMap = {};

  Object.keys(aliases).forEach(function (field) {
    const matches = headers
      .map(function (header, index) {
        return aliases[field].indexOf(header) !== -1 ? index + 1 : -1;
      })
      .filter(function (column) {
        return column !== -1;
      });

    if (matches.length !== 1) {
      throw new Error(
        'Row 1 must contain exactly one column for "' +
          aliases[field].join('" or "') +
          '". Found ' +
          matches.length +
          '.'
      );
    }
    headerMap[field] = matches[0];
  });

  return headerMap;
}

function cleanField_(value, maxLength) {
  return String(value || '').trim().slice(0, maxLength);
}

function safeCell_(value) {
  return /^[=+\-@]/.test(value) ? "'" + value : value;
}

function jsonResponse_(result) {
  return ContentService
    .createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## 2. Deploy the Apps Script as a public web app

1. In Apps Script, choose **Deploy → New deployment**.
2. Select the gear icon and choose **Web app**.
3. Set:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. Click **Deploy**, complete the authorization prompts, and copy the Web app
   URL ending in `/exec`.
5. Open that URL in a private/incognito window while signed out of Google. It
   should show the JSON message `JF Knowledge Centre contact endpoint is
   active.` and must not redirect to a Google sign-in page.

If a signed-out visitor is redirected to sign-in, the form cannot submit. A
Google Workspace administrator may need to allow public web app access. Do not
deploy with access limited to your organization for a public website.

## 3. Configure the website

The contact component reads the Vite variable `VITE_CONTACT_SCRIPT_URL`.

1. In the repository root, put the new `/exec` URL in `.env.local`:

   ```env
   VITE_CONTACT_SCRIPT_URL=https://script.google.com/macros/s/DEPLOYMENT_ID/exec
   ```

2. Restart `npm run dev` after changing `.env.local` to use it locally.
3. For production, set `VITE_CONTACT_SCRIPT_URL` in the hosting provider's
   environment settings and rebuild/redeploy the site.

`.env.local` is ignored by Git. `VITE_` variables are included in the public
browser bundle, so this URL is not a secret. Do not put credentials or private
keys in it.

## 4. Test and troubleshoot

1. Open the public `/exec` URL in a private browser window. The `doGet` status
   response confirms the deployed version is reachable without signing in.
2. Submit a test entry from the website and check for a new row under
   **Contact submissions**.
3. If no row appears, open Apps Script **Executions** and inspect the latest
   `doPost` run for its error. Also verify:
   - You ran `setupContactSheet` from the correct spreadsheet.
   - The deployment executes as **Me** and has permission to edit that Sheet.
   - The active deployment is the latest version of the script.
   - The website's local and hosting environment variables contain that
     deployment's `/exec` URL.

The React request uses `mode: 'no-cors'`, so the browser cannot read Apps
Script's JSON response. A browser-side request notice does not confirm that the
row was stored; the Sheet and Apps Script **Executions** are the source of truth.

## 5. Deploy script changes

After changing the Apps Script code, choose **Deploy → Manage deployments**,
edit the web app deployment, select **New version**, and deploy it. Keep the
same deployment URL if updating that deployment. Open the URL signed out and
submit another test entry to verify the new version.
